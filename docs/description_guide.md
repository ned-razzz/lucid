## 결론

좋은 설명은 **"결론부터 말하는 것"이 아니라 "처음 보는 사람도 바로 이해할 수 있는 결론부터 말하는 것"**이다.

핵심 원칙은 다음과 같다.

1. **첫 문장만으로 대략적인 뜻이 이해되어야 한다.**
2. **전문 용어보다 쉬운 의미를 먼저 설명한다.**
3. **추상적인 표현보다 구체적인 동작과 상황으로 설명한다.**
4. **원인과 결과 사이에서 이해에 필요한 연결고리는 생략하지 않는다.**
5. **현재 질문을 이해하는 데 필요한 맥락과 세부사항을 남긴다.**
6. **문장 길이보다 독자가 빠르게 이해할 수 있는지를 우선한다.**

설명 원칙을 한 문장으로 쓰면:

> **독자가 처음 읽을 때 핵심 의미와 구조를 이해할 수 있도록 필요한 맥락과 연결을 먼저 설명하고, 그다음 의미를 더하지 않는 표현만 덜어낸다.**
