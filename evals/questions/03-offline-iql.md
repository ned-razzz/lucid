# 목표 조건부 모방학습과 IQL 훈련 파이프라인의 일관성 진단

`uhlanga/research/movement_policy/colab_training.md`에서 이동 정책을
behavior cloning으로 학습한 뒤 IQL을 적용하고 있다. 행동 종류별 균등 샘플링과
가중 손실도 사용한다. 훈련은 실행되지만 이 조합이 정책을 개선하는지 판단하기
어렵다. 아래 코드 구조와 진단 결과를 토대로, 재학습 전에 무엇을 우선 수정하고
어떻게 검증해야 하는지 분석해 줘.

## 목표와 가치 모델 입력

- 정책은 관측 이력, 현재 경유지의 상대 위치, 경로 행동 종류 등을 포함한
  37차원 입력을 사용한다. Q·V도 정책과 같은 입력을 받는다.
- 보상과 종료 여부는 에피소드의 최종 목표를 기준으로 계산한다. 학습 자료를
  늘릴 때 기록 속 미래 방문 위치를 새로운 최종 목표로 재지정한다.
- 최종 목표를 재지정해도 현재 경유지와 모델 입력이 같을 수 있다. 실제 자료에서
  입력 이력·행동·다음 입력 이력·경과 시간은 같지만 보상 또는 종료 여부가 다른
  묶음이 1,637개 보고됐다.
- 한 쌍의 표본에서는 위 입력들이 같은데 한쪽은 보상 `−0.115`, 종료 `False`이고,
  다른 쪽은 보상 `+5.402`, 종료 `True`였다. 최종 목표는 서로 다르다.

## 행동 유지 시간과 결과 관측

전이 생성기는 관측 이후의 입력 변경을 해당 관측의 행동 정답으로 연결한다.
다음 관측은 입력 시작 시각에 유지 시간을 더한 시점 이전의 마지막 프레임을
선택하며, 최대 100ms 오차를 허용한다. 다음 사례가 재현됐다.

```text
0ms:   관측, 아무 키도 누르지 않음
90ms:  오른쪽 키를 누름
100ms: 다음 관측

저장된 행동 라벨: 오른쪽 키를 67ms 유지
저장된 결과:     100ms 시점의 관측
```

실제 적용 구간과 유지 시간 라벨의 평균 절대 차이는 약 30.85ms였고, 50ms를
넘는 전이는 1,387개, 최대 차이는 약 97.38ms였다. 최소 유지 시간 67ms를
확보하지 못해 건너뛴 후보 시점도 925개였다.

## 표본 선택과 손실

- BC는 경로 진전이나 도착이 있는 전이만 선택한다. 전체 자료에서 BC 제외 비율은
  `jump` 약 56%, `rope_transfer` 약 42%였다.
- IQL 정책 배치는 전체 `train_rows`에서 뽑으며 정책 손실은 다음과 같다.

```python
policy_loss = ((action_weights + 0.1) * imitation).mean()
```

- `action_weights`는 IQL의 advantage 기반 가중치다. BC의 빈도 가중치는 위
  IQL 정책 손실에 다시 곱하지 않는다.
- 균등 배치는 `edge_kind`별 표본 비중을 맞춘다. BC의 가중 손실은 같은
  `edge_kind` 안의 키 조합 빈도를 보정하며 종류별 평균 가중치를 1로 맞춘다.
  Q·V 학습 배치는 원래 전이 분포를 유지한다.
- BC 표본은 `walk` 2,412개, `approach_goal` 95개다. 보고된 BC 가중치 범위는
  약 0.558~2.621이다. 같은 프레임을 다른 목표로 재사용한 표본도 포함된다.

## 현재 평가와 진단 범위

- 위 수치는 ZIP 전체의 46개 세션에서 재생성한 전이 7,085개에 대한 진단이다.
  학습·평가 분리 후의 학습 표본 수나 실제 게임 성능은 아니다.
- BC 직후 가중치는 메모리에 보관하지만 BC와 최종 IQL 정책을 같은 평가 자료에서
  비교하지 않는다. 행동 일치율은 키 조합만 비교하고 유지 시간은 반영하지 않는다.
- 마지막 epoch를 저장한다. 중간에 더 좋은 정책이 있었는지는 현재 기록으로 알 수 없다.
- 기존 테스트 4개는 배치 구성, 모델 계산, 축소 학습·저장 연결을 확인한다.
  데이터 전이의 의미와 실제 도착 성능을 검증한 결과는 없다.

입력·행동·보상·종료가 한 학습 문제를 일관되게 표현하는지부터 검토해 줘.
특히 Q·V에만 최종 목표 정보를 추가하는 경우와 정책에도 추가하는 경우의 판단
기준, 유지 시간 오차가 가치 학습과 정책 학습에 미치는 영향을 설명해 줬으면 한다.

그다음 `+0.1` 항과 균등 샘플링이 각각 어떤 표본을 얼마나 강조하는지 분석하고,
서로 다른 보정을 단순히 중복 보정으로 볼 수 있는지도 판단해 줘. 수정 우선순위와
최소 비교 실험을 제안하되, 구현 오류·데이터 불일치·설계 선택·아직 확인하지 못한
성능 효과를 구별해서 설명해 줘. 실제 파일 수정이나 훈련 실행은 하지 마.
