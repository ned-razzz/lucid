# 실제 작업 기록에서 구성한 질문

세 질문은 로컬 Codex 대화에서 추가 설명 요청이 나온 질문과 답변을 바탕으로
재구성했다. 원문 질문을 그대로 복제한 것은 아니다. 도구 없이 실행할 수 있도록
당시 답변에서 보고된 코드 구조·수치·제약을 질문에 포함했다. 현재 프로젝트의
구현을 다시 확인한 자료나 정답·채점 기준은 아니다.

| 질문 | 기반 기록의 날짜 | 대화 ID |
|---|---|---|
| [키 입력 실행 순서](01-input-sequencing.md) | 2026-09-23 | `01a0cbf9-5774-7db2-9013-479fb0a623d9` |
| [영상 기반 맵과 위치 추정](02-visual-localization.md) | 2026-09-29 | `01a0eb03-969f-7d72-834b-5ddcc3d438af` |
| [목표 조건부 학습과 IQL](03-offline-iql.md) | 2026-10-14 | `01a13816-25b4-7520-b536-9e03c09967e1` |

출처는 `~/.codex/thread_history_1.sqlite`의 `thread_items`이다. 날짜는 한국 시간이다.
다음 항목 ID로 원래 질문·답변과 추가 요청을 확인할 수 있다.

- 키 입력: 원래 질문 `01a0cc17-2927-75c0-b988-5a1d1cd6cbb8`,
  답변 `msg_06e20609c517b569016ab339b3723887d099d80f9a7b4d8475`,
  추가 질문 `01a0cc1d-c725-73d2-ba08-859e6203c4df`.
  30ms 묶음의 추가 질문은 `01a0cc4f-d3c5-7662-a3f3-959192e4bffd`다.
- 위치 추정: 원래 질문 `01a0eba9-e4d8-7652-ba6a-e00497b12b4a`,
  답변 `msg_0325f273e86b6747016abb4e559d1487d08f762623e7a6be3e`,
  추가 질문 `01a0ebab-db82-7872-ad7b-1af0f3cb188c`.
  같은 대화에서 이어진 미니맵 보정·맵 생성 논의도 맥락에 포함했다.
- IQL: 원래 질문 `01a13917-b622-7530-a438-91bd7676d3ba`,
  답변 `msg_087e04a5a26e86d6016acf21ad5f58819194377e4f1527a584`,
  추가 질문 `01a13956-fe4a-7ee1-b566-cf76467908c1` 및
  재설명 요청 `01a13958-9d83-7711-9ab4-65d16639b8b1`.

추가 질문 원문과 이후의 해설은 비교 모델의 입력에 넣지 않았다. 세 조건은 같은
질문을 받고, 사용자가 직접 답변을 비교한다.
