# 답변 비교용 질문

질문 자체는 상황과 증상을 쉽게 이해할 수 있도록 쓰고, 답변에는 구체적인 원인
분석과 전문적인 해결 판단이 필요하도록 구성했다. 도구 없이 답할 수 있도록
필요한 배경과 조건은 각 질문 안에 포함했다.

| 질문 | 다루는 문제 | 구성 방식 |
|---|---|---|
| [AWS 서버를 두 대로 늘린 뒤 로그인 풀림](01-aws-login-session.md) | 서버마다 따로 저장한 로그인 정보와 서버 전환 | 평가용 가상 상황 |
| [게임 화면으로 지도와 현재 위치 찾기](02-visual-localization.md) | 움직이는 화면과 미니맵을 이용한 위치 보정 | 실제 작업 기록에서 재구성 |
| [딥러닝 학습 중 GPU 메모리 부족](03-deep-learning-gpu-memory.md) | 사진 8장씩 처리하면서 32장마다 모델을 수정하는 학습 절차 | 평가용 가상 상황 |

`evals/benchmark.py`를 인자 없이 실행하면 모든 질문을 처리한다.
하나만 실행하려면 질문 파일 경로를 지정한다. 실행 방법은
[평가 안내](../README.md)를 참고한다. 기본 응답·Lucid·한 문장 프롬프트의 세 조건은
같은 질문을 받고, 사용자가 직접 답변을 비교한다. 질문 파일에는 정답이나 채점
기준을 포함하지 않는다.

## 위치 추정 질문의 출처

02번 질문은 로컬 Codex 대화에서 추가 설명 요청이 나온 질문과 답변을 바탕으로
재구성했다. 원문을 그대로 복제한 것은 아니며, 현재 프로젝트의 구현을 다시
확인한 자료는 아니다.

출처는 `~/.codex/thread_history_1.sqlite`의 `thread_items`이다.
기반 기록의 날짜는 한국 시간으로 2026-09-29이며, 대화 ID는
`01a0eb03-969f-7d72-834b-5ddcc3d438af`다.

- 원래 질문: `01a0eba9-e4d8-7652-ba6a-e00497b12b4a`
- 답변: `msg_0325f273e86b6747016abb4e559d1487d08f762623e7a6be3e`
- 추가 질문: `01a0ebab-db82-7872-ad7b-1af0f3cb188c`

같은 대화에서 이어진 미니맵 보정·맵 생성 논의도 맥락에 포함했다.
추가 질문 원문과 이후의 해설은 비교 모델의 입력에 넣지 않았다.
