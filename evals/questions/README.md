# 답변 비교용 질문

각 질문은 하나의 기술적 판단에 집중한다. 도구 없이 답할 수 있도록 필요한 조건을
질문 안에 포함하며, 정답이나 채점 기준은 넣지 않는다.

| 질문 | 다루는 문제 |
|---|---|
| [서버를 두 대로 늘리면 왜 로그인이 풀릴까?](01-aws-login-session.md) | 여러 서버 사이의 로그인 정보 공유 |
| [같은 ROS 2 토픽인데 왜 메시지를 받지 못할까?](02-ros2-qos.md) | 발행자와 구독자의 QoS 호환성 |
| [이미지 분류 모델의 검증 데이터를 어떻게 나눌까?](03-ai-data-split.md) | 같은 부품의 사진이 학습·검증 데이터에 섞이는 문제 |

`evals/benchmark.py`를 인자 없이 실행하면 모든 질문을 처리한다.
하나만 실행하려면 질문 파일 경로를 지정한다. 실행 방법은
[평가 안내](../README.md)를 참고한다. 기본 응답·Lucid·한 문장 프롬프트의 세 조건은
같은 질문을 받고, 사용자가 직접 답변을 비교한다.

Lucid 답변에는 1번 `core`, 2번 `flow`, 3번 `steps` 레벨을 적용한다.
질문 파일을 개별 지정해도 같은 레벨을 사용한다.
