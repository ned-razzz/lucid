# GPU 메모리가 부족할 때 사진 32장씩 학습하는 효과를 유지할 수 있을까?

상품 사진을 보고 불량 여부를 구분하는 딥러닝 모델을 만들고 있다. 이미 학습된
이미지 분류 모델인 ResNet-50을 가져와 우리 사진으로 추가 학습하려고 한다.

참고한 학습 설정은 사진 32장의 예측 오차를 모아 모델을 한 번 수정한다.
그런데 내가 가진 GPU는 메모리가 8GB라서, 사진 32장을 한 번에 처리하면
메모리 부족 오류가 난다. 같은 설정에서 8장씩 처리하면 학습은 실행된다.

현재 조건은 다음과 같다.

- 사진 크기를 줄이면 작은 흠집이 보이지 않아서 입력 해상도는 유지해야 한다.
- GPU를 추가하거나 모델을 더 작은 것으로 바꾸기는 어렵다.
- 모델의 모든 층을 학습하며, 가중치를 수정하는 방법은 AdamW를 사용한다.
- 현재 코드는 사진 8장을 처리할 때마다 예측 오차를 계산하고 모델을 수정한다.
- 모델에는 BatchNorm 층이 있다. 이 층은 학습 중 한 번에 들어온 사진들의
  통계를 이용해 중간 계산값을 조정한다.

사진은 8장씩 처리하되, 32장의 결과를 모아서 모델을 한 번 수정하게 만들 수
있을까? 가능하다면 현재 학습 절차에서 무엇을 언제 계산하고, 언제 초기화하거나
모델에 반영해야 하는지 구체적으로 설명해 줘.

이렇게 바꾸면 32장을 실제로 한 번에 처리할 때와 학습 결과도 같다고 볼 수
있는지 궁금하다. 학습 자료 수가 32로 딱 나누어떨어지지 않을 때의 처리와,
메모리 사용량 및 학습이 올바른지 확인할 방법도 제안해 줘.

전체 모델 개발 과정 대신, 이 메모리 부족 문제를 해결하는 학습 절차에 집중해 줘.
